The film clips are not included here: together they are about 300 MB and
they come from the owner's own remuxes.

  rotk-clean / rotk-grain        master vs GRAINLIGHT, frame-aligned
  hobbit-ambient                 real ambient-light fill
  forrest-ambient                second ambient example
  spider-grain                   GRAINLIGHT output

To rebuild them: run extract.ps1 (cuts fragments from the 4K remuxes to
srcclips/) and then capture3.ps1 (plays each one in the real player with the
shaders running and grabs every frame). Both live in the project root.
